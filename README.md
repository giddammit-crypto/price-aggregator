# PriceHub (ТехноПульс) — Агрегатор цен электроники и техники (v3)

> Высокопроизводительный агрегатор цен для **обычного виртуального хостинга** на чистом **PHP 8.1+**, работающий **без СУБД** (MySQL/PostgreSQL) и без Node/Vite-сборок. Хранение организовано в шардированных NDJSON-паках с O(1) чтением через **OPcache** и атомарной сменой неизменяемых снимков (`snapshots`).

🌐 **Живой сайт (Демо на GitHub Pages):** [https://giddammit-crypto.github.io/price-aggregator/](https://giddammit-crypto.github.io/price-aggregator/)

Включает дизайн-систему, интегрированную через **Google Stitch MCP** (проект «TechRadar DNS Aggregator» / «ТехноПульс»), оптимизированную под мобильные устройства и десктоп в фирменном стиле DNS / techno-retail.

## 🏗 Архитектура хранилища (No-DBMS)

```
data/
├── catalog/products/     # 256 шардов товаров (p000..p255.ndjson + p000..p255.idx.php)
│   ├── p000.ndjson       # Упакованные строки JSON товаров и привязанных офферов
│   └── p000.idx.php      # [id => [byte_offset, byte_length]] — мгновенный fseek + fread
├── snapshots/            # Неизменяемые снимки каталога и инвертированного индекса поиска
│   ├── CURRENT           # Указатель на активный снимок (переключается атомарно через rename)
│   └── 20261003201912/   # Активный снимок: home.php, meta.php, categories.php, search/
├── items/{shop}/         # Сырые предложения магазинов по шардам s00..sff
├── history/              # Sharded append-логи цен для SVG-графиков динамики
├── subs/                 # Подписки на снижение цены (double opt-in)
├── logs/                 # Ротируемые логи кликов и переходов по дням
└── state/                # Курсоры cron, блокировки flock, курсы валют ЦБ РФ
```

### Принципы целостности:
1. **Читатели никогда не блокируются**: веб-запросы читают только активный неизменяемый снимок.
2. **Один писатель**: все обновления каталога выполняются фоновым cron-процессом с монопольной блокировкой `flock(LOCK_EX)`.
3. **Атомарная публикация**: компиляция нового снимка в соседнюю временную папку → `fsync` → атомарный `rename` файла `data/snapshots/CURRENT`.
4. **Контроль inodes**: товары упакованы в 256 файлов-паков вместо 20 000 отдельных файлов.

## 🚀 Быстрый старт

### 1. Системные требования
- PHP 8.1 или выше.
- Расширения: `json`, `mbstring` (или встроенный полифилл), `zlib`, `openssl`, `opcache`.
- Права на запись в каталог `data/`.

### 2. Запуск локального сервера
```bash
php -S 127.0.0.1:8000 -t public
```
Сайт будет доступен по адресу: [http://localhost:8000](http://localhost:8000)

### 3. Запуск тестов
```bash
# Полный тестовый запуск (Concurrency, FSCK, Matching, Smoke Tests)
php tests/run.php

# Проверка целостности файлового хранилища
php bin/fsck.php

# Быстрый smoke-тест всех публичных и административных URL
php bin/smoke.php
```

### 4. Генерация сидов и пересборка индекса
```bash
# Генерация 20 000 товаров и 110 000 офферов
php bin/seed.php

# Пересборка снимка каталога
php cron/run.php build_index
```

### 5. Настройка Cron на хостинге
В панели управления хостингом (cPanel, ISPmanager, Beget, TimeWeb) добавьте задание раз в 5–15 минут:
```bash
* * * * * /usr/bin/php /home/username/public_html/cron/run.php dispatch >/dev/null 2>&1
```

## 📦 Деплой на хостинг

1. Запустите сборку дистрибутива:
   ```bash
   php bin/build-dist.php
   ```
2. Загрузите полученный архив `dist.zip` в корень сайта на хостинге и распакуйте.
3. Убедитесь, что Web-Root (DocumentRoot) сервера указывает на папку `public/`.
4. Папка `data/` находится вне пределов публичного доступа или защищена встроенным `.htaccess`.
5. Создайте резервную копию при необходимости:
   ```bash
   php bin/backup.php
   ```
