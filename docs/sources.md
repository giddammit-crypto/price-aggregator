# Реестр источников данных (Магазины и Маркетплейсы)

Дата ревизии: 03.10.2026

## Магазины (Розничные сети РФ)

| Источник | Канал данных | Режим | Формат | Ограничения RPS | Ответственный |
|---|---|---|---|---|---|
| Ситилинк | Партнёрская сеть (CPA / Admitad) | prices | YML-фид | 1 запрос / 4 часа | Ingestion Agent |
| Регард | Публичный прайс-лист / YML | prices | YML / XML | 1 запрос / 6 часов | Ingestion Agent |
| Онлайнтрейд | Партнёрский YML | prices | YML | 1 запрос / 6 часов | Ingestion Agent |
| М.Видео-Эльдорадо | CPA-сеть | prices | YML-фид | 1 запрос / 12 часов | Ingestion Agent |
| DNS | Официальный фид отсутствует | link_only | Поисковый диплинк | Без прямых запросов цен | Research Agent |
| КомпМаркет / НИКС | Прайс-лист | prices | YML | 1 запрос / сутки | Ingestion Agent |

## Маркетплейсы (РФ и Трансграничные)

| Площадка | Канал данных | Режим | Особенности | Ответственный |
|---|---|---|---|---|
| Ozon | Партнёрская программа (Admitad / фид) | prices | Учёт цен «с Ozon Картой» как `price_note`, FBO/FBS | Marketplace Agent |
| Wildberries | Публичного фида для агрегации нет | link_only | Поисковый переход с диплинком | Marketplace Agent |
| Яндекс Маркет | Реферальная программа | prices | Маркетплейс + магазины | Marketplace Agent |
| Мегамаркет (Сбер) | Партнёрский фид | prices | Бонусы «СберСпасибо», доставка | Marketplace Agent |
| AliExpress | AliExpress Affiliate (Portals) API | prices | HMAC-SHA256 подпись, конвертация CNY/USD -> RUB через курс ЦБ, таможня и доставка | Marketplace Agent |
| Joom | Партнёрский фид | prices | Трансграничная доставка | Marketplace Agent |
| Авито | Раздел «Б/у» | link_only | Диплинк на частные объявления | Marketplace Agent |

## Юридический регламент
1. Парсинг закрытых API и обход средств защиты запрещены.
2. Маркетплейсы без прямого фида/API подключаются строго в режиме `link_only`.
3. Все ссылки на магазины размечаются атрибутом `rel="sponsored nofollow noopener"`.
